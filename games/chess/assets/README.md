# Chess piece SVGs

These 12 standard transparent chess piece SVGs are by **Cburnett**, downloaded
without modification from [Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces/Standard_transparent).
The original file pages offer multiple licenses; this project uses **Creative
Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0)** for these assets.

License: https://creativecommons.org/licenses/by-sa/3.0/
Author: https://commons.wikimedia.org/wiki/User:Cburnett

`sources.json` records the source file page, original download URL, author and
license for each asset. Attribution is also included in the game's help page,
which is distributed with production builds. The CC BY-SA license applies to
these image assets; the game code is a separate work. Changes to these assets
must be attributed and distributed under the same or a compatible license.

File naming: `l` = light/white, `d` = dark/black, `t` = transparent background;
`k`, `q`, `r`, `b`, `n`, `p` = king, queen, rook, bishop, knight, pawn.
