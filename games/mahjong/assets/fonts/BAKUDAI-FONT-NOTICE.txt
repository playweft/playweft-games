Bakudai Brush Font / 莫大毛筆字體

Source: https://github.com/max32002/bakudaifont
Upstream version used for this subset: 1.48 Regular

Bakudai is derived from Aoyagi Kouzan's Kouzan Brush Font Gyousho. This
project embeds one WOFF2 subset, `bakudai-mahjong.woff2`, for all Mahjong UI
labels, 3D canvas text, result-paper yaku names, and draw-result reasons. The
generated glyph list is `mahjong-brush-text.txt`; rebuild the subset with
`bash build-bakudai-subset.sh /path/to/Bakudai-Regular.woff2` after changing
that list. The list is generated by `build/fonts/mahjong-brush-text.js` from
menu labels, room-entry states, career result labels and grades, round/wind text, actions, result controls,
draw reasons, and traditional yaku names. The script checks the emitted cmap
and fails on missing glyphs. Missing simplified 继/续/厅/联/赛/开 codepoints
use the corresponding 繼/續/廳/聯/賽/開 glyphs to preserve existing UI strings.
The build script requires FontTools with WOFF2 support
(`pip install 'fonttools[woff]'`).
